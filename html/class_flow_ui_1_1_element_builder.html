Detailed Description

template<typename Parameters = NoElementParameters, typename State = void, typename Resources = void, uint64_t DefinitionId = 0, bool IsDevInternal = false>
class FlowUi::ElementBuilder< Parameters, State, Resources, DefinitionId, IsDevInternal >

builder returned by UiManager::createElement().

ElementBuilder stores the element definition, element id, and parameter values for one element invocation. The builder is normally created through UiManager::createElement(); users should not need to construct it directly.

The final call is usually draw() or construct(). draw() executes the element's draw flow immediately. construct() opens and configures the element root for a manual closing flow.

Replace the element id string stored by the builder.

This changes the Flow element id used by later draw() or construct() calls. It is most useful when an ElementBuilder is stored in a local variable and emitted later with an id chosen after the builder was created.

Parameters
elementIDReplacement Flow element id string.
Returns
Reference to this builder for fluent chaining.

.setParameters(ButtonParams{.label = "Open"});

button.withElementID(buttonId).draw();

Detailed Description

Per-frame input snapshot consumed by FlowUi managers and elements.

FrameInput is the normalized input state for one FlowUi frame. App builds it from the active window backend, scales pointer and scroll values into FlowUi layout space, and then passes it through UiManager to input fields, shortcuts, and custom element interaction callbacks.

Keyboard state is stored as backend key slots. In the default backend those slots are GLFW-compatible key codes. Text input is stored separately as Unicode codepoints received during the frame.

Keyboard key down states for the current frame.

Each entry is true while the corresponding backend key slot is held. For command shortcuts, prefer ShortcutManager unless the element needs direct low-level key state.

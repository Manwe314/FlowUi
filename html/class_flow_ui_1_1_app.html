◆ beginFrame()

void FlowUi::App::beginFrame ( )

Begin a frame and prepare input/UI state.

Polls the window backend and prepares per-frame UI resources and state. This function updates the frame input snapshot, refreshes frame-dependent state, and initializes the UI system using the current window dimensions and UI scale configuration.

Example:

application.beginFrame();
buildUi(application);
application.endFrame();
Precondition
The FlowUi::App instance is initialized and its window/UI systems are valid.
Postcondition
The current frame is active and input/UI state is ready for frame logic/building.
Note
This function should be called exactly once per frame.

◆ drawFrame()

void FlowUi::App::drawFrame ( )

Submit the current frame for rendering and presentation.

Takes the render commands output by endFrame(), builds GPU draw runs, renders them, and passes the output to the swapchain for presentation.

Example:

application.endFrame();
application.drawFrame();
Precondition
FlowUi::App::endFrame() was called successfully.
Postcondition
This frame is rendered and presented.
Note
This function should be called exactly once per frame.

◆ endFrame()

void FlowUi::App::endFrame ( )

End UI construction and produce render commands.

Completes UI construction, produces render commands for this frame, and prepares viewport and icon manager resources.

Example:

buildUi(application);
application.endFrame();
application.drawFrame();
Precondition
FlowUi::App::beginFrame() was called and UI was built afterward.
Postcondition
Render commands for this frame are ready and viewport handles are sized.
Note
This function should be called exactly once per frame.

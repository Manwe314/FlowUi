Detailed Description

Stub IconManager used when FlowUi is built with icon support disabled.

This struct preserves the public type when FLOWUI_INCLUDE_ICON_MANAGER is disabled. Public calls throw std::runtime_error so code paths that require icon support fail explicitly.

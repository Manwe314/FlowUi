Detailed Description

Configures FlowUi developer tooling and capture behavior.

These options are only used when developer mode support is compiled in.

Member Data Documentation

◆ autoSave

bool FlowUi::DevToolsConfig::autoSave = true

Request automatic saving of developer changes.

Note
No-op in v0.9.0; developer data is only written by explicit export paths.

◆ excludeInternalDevElementsFromCapture

bool FlowUi::DevToolsConfig::excludeInternalDevElementsFromCapture = true

Hide FlowUi's internal developer elements from captured UI data.

Note
Keeping this enabled is strongly recommended. Capturing the developer panel itself can add noisy internal elements to inspection/export data and make user-authored UI harder to reason about.

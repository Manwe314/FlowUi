Detailed Description

Input field request submitted by UI code.

A custom input element calls InputFieldManager::requestField while building its Clay nodes. The request marks the field as present for the current frame, updates its behavior config and element ids, and returns the manager-owned text state through FieldQueryResult.

Clay content element id for pointer hit testing.

The id should refer to the clickable/editable field area. When available, FlowUi uses it to place the caret in empty space and to resolve pointer focus.

std::string_view FlowUi::FieldRequest::fieldId {}

Stable field id.

This id keys the persistent text and caret state. Use a value that remains stable across frames for the same logical field.

◆ initialText

std::string_view FlowUi::FieldRequest::initialText {}

Initial text used when the field state is first created.

The value is copied only when fieldId has no existing managed state. Later requests with the same fieldId preserve the current edited text.

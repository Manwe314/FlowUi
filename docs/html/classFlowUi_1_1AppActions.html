Detailed Description

Retained application actions addressed by stable AppActionID values.

Obtain this facade from ActionManager::appActions(). Calls resolve the current binding at invocation time, so existing AppActionCall values follow rebinds. Referenced objects remain caller-owned and must outlive every invocation.

◆ invoke()

ActionInvocationStatus FlowUi::AppActions::invoke ( AppActionCall call)
nodiscard

Invoke synchronously and directly return Invoked, Empty, Unbound or Disabled. An unavailable call does not run its callable.

Callback and owned-result movement exceptions propagate unchanged. Side effects are not rolled back or automatically retried. invokeFor requires nonthrowing destruction of owned payloads; reference and array result types are rejected.

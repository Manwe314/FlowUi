Detailed Description

Startup storage capacities, explicit container reserves, growth policy, and profiling provenance. storage provides typed byte-capacity hints for storage pools and buffers. settings addresses individual registered targets by stable ID, including storage byte capacities and manager container capacities in each target's registered units (bytes or entries). Nonzero storage hints are converted to settings during startup resolution; zero storage hints preserve library defaults. Explicit settings override storage hints for the same target, and a zero setting selects that target's default. Enabled baked capacities take precedence over both.

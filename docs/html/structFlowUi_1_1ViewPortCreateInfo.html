Detailed Description

Creation settings for a viewport render target.

ViewPortCreateInfo controls the image format and clear behavior for a viewport. The actual target size is selected by FlowUi from the UI image area where the viewport texture is used.

bool FlowUi::ViewPortCreateInfo::clearEveryFrame = true

Whether the viewport should be cleared every frame.

When false, FlowUi loads the previous contents after the image has been initialized, allowing persistent viewport rendering patterns.

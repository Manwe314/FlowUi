Detailed Description

App-owned dispatcher for retained semantic actions and compact UI calls.

Obtain the initialized manager through App::actions() or UiManager::actions(). Calls run synchronously on the caller's thread. The manager owns retained binding records, while callables and resource references follow the borrowing contracts of AppActions::bind() and UiActions::make().

◆ visitDevActions()

Result< bool > FlowUi::ActionManager::visitDevActions ( void * userData,
DevActionVisitor visitor ) const
nodiscardnoexcept

Available only with FLOW_UI_DEV_MODE. Synchronously visit borrowed catalogue entries. Successful true means the visit completed; successful false means a visitor stopped early or storage/visitor was unavailable. Thrown visitor/storage failures are converted to structured errors. Do not retain views or references to their metadata beyond the call.

Example
#if FLOW_UI_DEV_MODE
std::size_t boundCount = 0;
auto result = actions.visitDevActions(&boundCount,
[](void* userData, const FlowUi::ActionManager::DevActionView& view) {
auto& count = *static_cast<std::size_t*>(userData);
if (view.debug.bound) ++count;
return true;
});
if (!result) {
throw FlowUi::FlowUiException(result.error());
}
const bool completed = *result;
#endif

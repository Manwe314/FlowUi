Detailed Description

Bounded ingress for native/translator events. Emission is thread safe and never allocates. Worker producers must stop before their sink is destroyed. Emission errors distinguish invalid input, an uninitialized sink and queue overflow. After overflow, the input engine cancels affected held state before consuming subsequent input. Success means queue acceptance, not delivery.

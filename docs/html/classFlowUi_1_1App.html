Detailed Description

Main FlowUi application object and owner of runtime managers.

Create an initialized app with makeApplication(). Use it on its platform thread and complete beginFrame(), endFrame(), drawFrame() for one window before beginning another. No-argument window APIs select mainWindowId(). Manager references are borrowed from the app or the selected window and must not be used after their owner is destroyed or replaced by move assignment. App Result/Status operations contain operational failures and preserve their FlowUiError. Ordinary builders, context access and action invocation instead use direct values/references and propagate exceptions while poisoning a failed composition frame. runFrame() owns build cancellation and callback recovery.

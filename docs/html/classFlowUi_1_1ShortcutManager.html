Detailed Description

Registers and dispatches keyboard shortcuts.

ShortcutManager stores keyboard chords and evaluates them once per FlowUi frame from the current and previous FrameInput. Matching shortcuts are filtered by ShortcutScope, then invoked in priority order. A callback that returns true handles the chord and stops later callbacks for that same match.

ShortcutId value 0 is reserved as an invalid id. registerShortcut() returns an error when registration fails, so application code can treat 0 as "not registered".

Register a keyboard chord and return its window-local registration ID.

Matching uses exact modifier requirements and the trigger transition. FocusedInput precedes FocusedElement, then Global; higher priority first, then registration order. Callbacks are owned by the registration, so captured references must outlive it. A callback returning true consumes the chord; false allows subsequent matches. Callback exceptions follow the dispatch/frame boundary policy, not the registration call.

Returns
Success contains a nonzero ShortcutId; invalid manager/chord/callback/action or allocation failures are errors. Recoverable initialization, validation, allocation, and storage failures are returned as FlowUiError; no exception escapes this noexcept operation.

saveRequested = true;
return true;

Observe development catalogue entries without invoking application operations.

Development-only synchronous observation under FLOW_UI_DEV_MODE. The example counts live shortcut registrations; completed is the separate successful bool payload. Views and their text/pointers/handles are borrowed; copy needed values during the callback, do not mutate the catalogue while visiting, and do not retain callback arguments. Visitor exceptions are converted to FlowUiError. Earlier callback effects, including the counter, are not rolled back on failure.

Returns
Success contains true after visiting the whole catalogue (including an empty catalogue), or false when a visitor stops or for a detached manager or null visitor. A failed Result is an operational/callback error, not an incomplete-visit bool.

if (shortcut.id != 0) {
++observedCount;
}
return true;
});
if (!result) {

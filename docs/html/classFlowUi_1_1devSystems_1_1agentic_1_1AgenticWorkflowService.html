◆ configure()

Status FlowUi::devSystems::agentic::AgenticWorkflowService::configure ( const AgenticWorkflowConfig & configuration)
nodiscardnoexcept

Resolve one launch handoff; explicit configuration takes precedence over environment. Initial setup failure leaves admission disabled and releases partially started local endpoints. A reserved run is retained with failed session status; retry uses a fresh run ID. Filesystem failure can prevent the failure marker from being published. Existing runs are never removed or reused after a failed attempt. Reconfiguring an already configured service is rejected without changing it.

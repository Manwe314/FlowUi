Detailed Description

Typed startup capacities for storage pools and buffers, measured in bytes. Zero preserves defaults. MemoryCapacityProfile::settings overrides matching hints; enabled baked capacities override both. Later storage growth follows the profile and error policy; these values set initial reserves.

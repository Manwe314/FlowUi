Detailed Description

App-shared image loading and generation-checked texture lookup.

Recoverable operations return checked Result/Status values. A successful bool payload may be false; inspect the payload only after checking the Result. Obtain App-owned managers through the checked App getter and unwrap its reference_wrapper with result->get(). Returned text, metadata, resource views, and pointers remain borrowed under each operation's documented invalidation rules.

Observe development catalogue entries without invoking application operations.

Development-only synchronous observation under FLOW_UI_DEV_MODE. The example counts named image registrations; completed is the separate successful bool payload. Views and their text/pointers/handles are borrowed; copy needed values during the callback, do not mutate the catalogue while visiting, and do not retain callback arguments. Visitor exceptions are converted to FlowUiError. Earlier callback effects, including the counter, are not rolled back on failure.

Returns
Success contains true after visiting the whole catalogue (including an empty catalogue), or false when a visitor stops or for a null visitor. A failed Result is an operational/callback error, not an incomplete-visit bool.
#if FLOW_UI_DEV_MODE
std::size_t count = 0;
auto result = manager.visitDevImages(&count,
[](void* target, const FlowUi::ImageManager::DevImageView& image) {
auto& observedCount = *static_cast<std::size_t*>(target);
if (!image.key.empty()) {
++observedCount;
}
return true;
});
if (!result) {
throw FlowUi::FlowUiException(result.error());
}
const bool completed = *result;
#endif

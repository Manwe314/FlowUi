Detailed Description

Loads image files and exposes them as FlowUi texture references.

ImageManager uploads decoded image files as standalone Vulkan textures and registers them under application-defined keys. The returned TextureRef can be passed to FlowUi image drawing code and adjusted with TextureRef options such as fitMode and tintEnabled.

◆ getTexture()

TextureRef FlowUi::ImageManager::getTexture ( ResourceKey key) const
nodiscard

Return the texture reference for a registered image key.

The returned TextureRef contains a generation-checked logical handle and source image dimensions. If key is missing, this function returns an invalid handle and reports the missing key once. The result and its source key borrow manager-owned metadata; removal invalidates the handle.

Application code may adjust TextureRef fields such as fitMode and tintEnabled before passing it to image drawing code. Manager-owned handle and UV fields should be left unchanged.

Parameters
keystring image key to resolve.
Returns
TextureRef for key, or an invalid fallback reference when missing.

◆ registerImage()

Result< bool > FlowUi::ImageManager::registerImage ( ResourceKey key,
std::string_view filePath )
nodiscard

Load and register an image from disk under a caller-provided key.

The image is decoded with stb_image and uploaded as an RGBA8 sRGB Vulkan texture. Supported file formats are the stb_image formats compiled into FlowUi: JPEG, PNG, TGA, BMP, PSD, GIF, HDR, PIC, PNM/PPM, and PGM.

Registering an existing key replaces the previous image resource and keeps the key active with the new texture data.

Parameters
keystring image key.
filePathPath to an image file on disk.
Returns
A result whose value is true for a newly registered key or false when an existing image was replaced. Initialization, key, file, decode, and upload failures are returned as structured errors.
Exceptions
std::bad_allocif allocating path or registration metadata fails.

Result< bool > FlowUi::ImageManager::removeImage ( ResourceKey key)
nodiscard

Remove a registered image by key.

Removing an image retires its logical texture generation and GPU resource after the exact last storage submission completes. TextureRef values previously returned for the key should be treated as invalid after removal.

Parameters
keystring image key to remove.
Returns
A result whose value is true when an image was removed or false when the key was absent. Initialization and storage failures are returned as structured errors.

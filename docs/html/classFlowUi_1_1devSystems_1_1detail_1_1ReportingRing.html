Detailed Description

template<class Value>
class FlowUi::devSystems::detail::ReportingRing< Value >

Bounded chronological storage. Appending/evicting never moves retained payloads. Slot contents survive eviction for buffer reuse; references expire on reuse/reconfiguration.

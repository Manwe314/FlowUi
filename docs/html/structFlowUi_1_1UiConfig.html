Detailed Description

Layout, font, and text-editing defaults shared by application windows at startup. Temporary UI storage is sized by StorageMemoryCapacities::transientBytesPerFramePerWindow.

◆ dpi

float FlowUi::UiConfig::dpi = 96.0f

Logical dots per inch for text: pixels = points * dpi / 72 * fontScale. Initialization clamps dpi to at least one; 12 points at 96 dpi and scale one is 16 pixels.

◆ fontAtlasSize

Detailed Description

Configures FlowUi layout, text, and UI resource defaults.

These values are consumed during app and UI manager initialization. They affect Clay layout memory, transient per-frame UI storage, text scaling, and the default font resources used by text rendering.

◆ clayArenaCapacityBytes

size_t FlowUi::UiConfig::clayArenaCapacityBytes = 0

Byte capacity of the persistent Clay layout arena.

A value of 0 uses Clay_MinMemorySize(). Non-zero values are clamped up to at least Clay_MinMemorySize() before Clay_Initialize is called.

◆ defaultFontFamily

Default font family loaded during app startup.

This family is registered first, so family id 0 is the fallback family used by default text rendering. If loading fails, FlowUi attempts built-in fallback font candidates.

◆ dpi

float FlowUi::UiConfig::dpi = 96.0f

Logical dots-per-inch used for point-to-pixel conversion.

Text sizes are specified in points and converted to pixels as dpi / 72. Values below 1 are clamped to 1 during initialization.

For example, a 12 pt text size at the default 96 dpi is laid out as 12 * (96 / 72) = 16 px before fontScale is applied.

◆ fontAtlasSize

uint32_t FlowUi::UiConfig::fontAtlasSize = 2048

Width and height in pixels of each font atlas page.

The font manager uploads each loaded font face into square atlas layers of this size. The value must be non-zero and large enough for the source .arfont atlas or runtime-baked glyph atlas.

◆ fontScale

float FlowUi::UiConfig::fontScale = 1.0f

Global multiplier applied after DPI font scaling.

If the configured value is zero or negative, FlowUi falls back to the DPI-derived point-to-pixel scale.

◆ stringArenaSize

size_t FlowUi::UiConfig::stringArenaSize = 256 * 1024

Byte capacity of each transient UI arena.

FlowUi creates one arena per frame in flight and resets the active arena at the beginning of each UI frame. These arenas store temporary Clay strings, element ids, and texture references created during UI construction.

Note
The Size set here is for ONE arena. Total Size used will be stringArenaSize * framesInFlight
See also
FlowUi::VulkanConfig::framesInFlight

◆ uiScale

float FlowUi::UiConfig::uiScale = 1.0f

Global layout scale applied to UI coordinates and input.

Values above 1 make the logical layout space smaller relative to the native window size, producing larger rendered UI.

Detailed Description

Renderer texture reference returned by image, icon, and viewport managers.

Treat this as a manager-owned handle with optional render settings. After obtaining a TextureRef, application code may adjust fitMode, samplingMode, and tintEnabled. The handle, UV coordinates, and source dimensions are populated by FlowUi managers and should normally be left unchanged.

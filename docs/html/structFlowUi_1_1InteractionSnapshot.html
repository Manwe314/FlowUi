Detailed Description

Snapshot of per-element interaction state for one completed frame.

InteractionSnapshot records the Clay elements that were hovered, pressed, held, or released when FlowUi finalized a frame. Element callbacks receive the previous completed snapshot so they can query stable interaction results while constructing the next frame. References obtained from UiManager borrow its snapshot and should not be retained as immutable history across later frames. Each observer accepts Clay_ElementId, FlowElementID, GlobalFlowID and FlowElementPartID directly and returns a plain bool without a Result wrapper.

Press, hold, and release currently describe the primary pointer button over hovered elements. The same element can appear in more than one list if the underlying interaction state makes that true for the snapshot.

Example
const bool hovered = snapshot.isHovered(clayId);
const bool pressed = snapshot.isPressed(localId);
const bool held = snapshot.isHeld(globalId);
const bool released = snapshot.isReleased(partId);

Result< App > FlowUi::makeApplication ( const AppConfig & cfg)
nodiscardnoexcept

Create a running FlowUi application from configuration.

Creates an App object, allocates its internal implementation, and initializes the runtime managers.

Parameters
cfgConfiguration struct used for initialization.
Returns
Sole owner of the initialized runtime and semantic main window, or a structured configuration, allocation, platform, resource, or rendering error.
Note
Runtime access and window/frame work must remain on the creating platform thread.
Check success before continuing or reading a value. This noexcept App boundary returns operational failures as FlowUiError and preserves their attribution. Caller argument construction occurs before entry.
Example
FlowUi::AppConfig configuration{};
auto result = FlowUi::makeApplication(configuration);
if (!result) {
throw FlowUi::FlowUiException(result.error());
}
FlowUi::App application = std::move(*result);

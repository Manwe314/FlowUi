Detailed Description

Font-face registration request for a baked .arfont asset or a source font. Source fonts require runtime font baking support; baked assets use their authored metrics.

Member Data Documentation

◆ baked_data

std::span<const std::byte> FlowUi::FontFaceCreateInfo::baked_data {}

Optional borrowed .arfont bytes, consumed synchronously during family/face registration. Nonempty data takes precedence over path; its storage need only outlive the registration call. If retained in UiConfig, keep the bytes alive until application initialization completes.

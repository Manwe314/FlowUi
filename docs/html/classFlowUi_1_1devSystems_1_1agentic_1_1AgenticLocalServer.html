Detailed Description

Bounded owner-private local command server, independent of MCP and application stdout. The owning thread serializes start/stop/destruction; handlers execute on borrowed workers.

◆ stop()

Status FlowUi::devSystems::agentic::AgenticLocalServer::stop ( )
nodiscardnoexcept

Stop admission, interrupt pending input and join every worker before releasing its handler. A handler cannot join its own worker: that call returns Busy and the owner must stop the server after the handler returns. The server must outlive all handler calls.

Detailed Description

Creates, tracks, renders, and exposes offscreen viewports.

ViewPortManager is owned by App and is available through App::viewPorts() when FLOWUI_PUBLIC_VULKAN_INTEROP is enabled. It creates named offscreen render targets, exposes them as TextureRef values for Clay image elements, sizes them from the UI image area that references them, and invokes ViewPort render callbacks during App's render pass.

The manager owns all viewport images, image views, texture slots, command pools, and command buffers. User code configures viewports and records rendering through callbacks; App performs lifecycle, synchronization, image transitions, and presentation integration.

Warning
Vulkan interop resources returned by getVulkanInterop() are App-managed. Do not destroy or replace those handles from application code.

◆ visitDevViewports()

Result< bool > FlowUi::ViewPortManager::visitDevViewports ( void * target,
DevViewportVisitor visitor ) const
nodiscardnoexcept

Observe development catalogue entries without invoking application operations.

Development-only synchronous observation under FLOW_UI_DEV_MODE. The example counts sized viewport registrations; completed is the separate successful bool payload. Views and their text/pointers/handles are borrowed; copy needed values during the callback, do not mutate the catalogue while visiting, and do not retain callback arguments. Visitor exceptions are converted to FlowUiError. Earlier callback effects, including the counter, are not rolled back on failure. This does not schedule rendering or capture; capture_texture is an observation-cache binding and must not be retained as ownership.

Returns
Success contains true after visiting the whole catalogue (including an empty catalogue), or false when a visitor stops or for a detached manager or null visitor. A failed Result is an operational/callback error, not an incomplete-visit bool.
#if FLOW_UI_DEV_MODE && FLOWUI_PUBLIC_VULKAN_INTEROP
std::size_t count = 0;
auto result = manager.visitDevViewports(&count,
[](void* target, const FlowUi::ViewPortManager::DevViewportView& viewport) {
auto& observedCount = *static_cast<std::size_t*>(target);
if (viewport.width != 0 && viewport.height != 0) {
++observedCount;
}
return true;
});
if (!result) {
throw FlowUi::FlowUiException(result.error());
}
const bool completed = *result;
#endif

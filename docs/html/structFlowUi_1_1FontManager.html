Detailed Description

App-shared font-family registration and face resolution.

Recoverable operations return checked Result/Status values. A successful bool payload may be false; inspect the payload only after checking the Result. Obtain App-owned managers through the checked App getter and unwrap its reference_wrapper with result->get(). Returned text, metadata, resource views, and pointers remain borrowed under each operation's documented invalidation rules.

Observe development catalogue entries without invoking application operations.

Development-only synchronous observation under FLOW_UI_DEV_MODE. The example counts loaded face rows; completed is the separate successful bool payload. Views and their text/pointers/handles are borrowed; copy needed values during the callback, do not mutate the catalogue while visiting, and do not retain callback arguments. Visitor exceptions are converted to FlowUiError. Earlier callback effects, including the counter, are not rolled back on failure.

Returns
Success contains true after visiting the whole catalogue (including an empty catalogue), or false when a visitor stops or for a detached manager or null visitor. A failed Result is an operational/callback error, not an incomplete-visit bool.

if (face.face != nullptr) {
++observedCount;
}
return true;
});
if (!result) {

◆ kAtlasLayerGrowthStep

uint32_t FlowUi::FontManager::kAtlasLayerGrowthStep = 4
staticconstexpr

Number of atlas array layers added when the font atlas grows.

When registered faces exceed the current capacity, FlowUi::FontManager creates a larger atlas image and copies the already-uploaded layers into it. Capacity grows in fixed steps of this many layers to avoid reallocating for every additional face.

◆ kInitialAtlasLayerCapacity

uint32_t FlowUi::FontManager::kInitialAtlasLayerCapacity = 4
staticconstexpr

Number of font atlas array layers allocated for the first atlas image.

A layer is one square atlas page of UiConfig::fontAtlasSize by UiConfig::fontAtlasSize pixels. Because each loaded face is uploaded into one layer, this value is the number of faces the initial atlas allocation can hold before storage has to grow.

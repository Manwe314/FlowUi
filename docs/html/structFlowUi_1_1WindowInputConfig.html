Detailed Description

Configures low-level window input behavior.

These options are forwarded to the window backend during window creation and whenever the input configuration is updated at runtime.

Member Data Documentation

◆ lockKeyMods

bool FlowUi::WindowInputConfig::lockKeyMods = false

Preserve lock-key modifier state in reported input events.

When supported by the backend, events include Caps Lock and Num Lock modifier bits while those locks are active.

◆ rawMouseMotion

bool FlowUi::WindowInputConfig::rawMouseMotion = false

Request unaccelerated mouse motion when the backend supports it.

Unsupported backends or platforms disable this option automatically.

◆ stickyKeys

bool FlowUi::WindowInputConfig::stickyKeys = false

Keep key press events available until they are polled.

Useful when the app wants to avoid missing short key presses between input polling points.

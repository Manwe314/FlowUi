Acquire translators in declaration order, rolling back earlier successful acquisitions in reverse order on failure. The failing translator must clean up its own partial acquisition. Reinitialization returns ObjectAlreadyInitialized; thrown exceptions become a failed Status.

◆ poll()

template<InputTranslatorConcept... Translators>
Status FlowUi::InputTranslatorPack< Translators >::poll ( const InputTranslatorContext & context,
InputSink & sink )
inlinenodiscardnoexcept

Poll acquired translators in declaration order, stopping at the first failure. Earlier emissions remain in sink. Direct consumers must reject/cancel that tick, reset affected targets and resynchronize external device state before reuse. App-owned polling already cancels routed state and clears translated queues. resetTarget/shutdown release external captures; they do not undo SDK side effects.

Example
const auto status = pack.poll(context, sink);
if (!status) {
pack.resetTarget(window, sink);
throw FlowUi::FlowUiException(status.error());
}

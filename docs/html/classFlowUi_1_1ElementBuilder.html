Detailed Description

template<FlowElement Element>
class FlowUi::ElementBuilder< Element >

Builder returned by UiManager::createElement().

ElementBuilder owns an element instance's logical id and parameter values. Element behavior is selected entirely from ElementType at compile time; the constexpr tag passed to createElement() is never stored.

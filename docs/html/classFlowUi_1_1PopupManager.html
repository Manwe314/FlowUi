Detailed Description

Window-owned placement, layering, and dismissal service for popup elements.

Obtain this manager through UiManager::popups(). Request each open popup once during UI construction and use its PopupFrame to emit the floating Clay root. Placement and dismissal state participate in the window's frame commit.

Result< PopupFrame > FlowUi::PopupManager::request ( FlowElementID popupId,
const PopupRequest & request )
nodiscardnoexcept

Submit an open popup for the active window UI build.

Request each popup once per active build. Emit the floating root when visible or measureOnly, using its floating configuration. Placement/dismissal participate in commit; canceling the build rolls them back. Default unknown-size policy uses a hidden measurement frame.

Returns
Success contains PopupFrame, which may be hidden or measureOnly; a zero ID yields an empty frame. Inactive frame or configured duplicate/placement failures return errors. Recoverable initialization, validation, allocation, and storage failures are returned as FlowUiError; no exception escapes this noexcept operation.
FlowUi::PopupRequest request{};
request.anchor = FlowUi::PopupAnchor::parent();
request.expectedSize = Clay_Dimensions{240.0f, 160.0f};
auto result = manager.request(fieldId, request);
if (!result) {
throw FlowUi::FlowUiException(result.error());
}
const auto popup = *result;

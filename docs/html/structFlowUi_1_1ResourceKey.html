Detailed Description

Human-readable logical identity accepted by FlowUi managers.

ResourceKey is a non-owning call-site value. Managers intern name before the call returns. ResourceDomain::Auto selects the receiving manager's domain. A zero window selects app scope for app-shared managers and the manager's owning window for window-local managers.

Detailed Description

Window-owned editable text, caret state, and atomic edit operations.

Authoring operations return direct values and propagate exceptions to the frame boundary. Operational exceptions latch frame failure. False, empty snapshots and EditResult rejection values are ordinary outcomes; frameStatus() remains the checked query for a latched failure. Obtain App-owned managers through the checked App getter and unwrap its reference_wrapper with result->get(). Returned text, metadata, resource views, and pointers remain borrowed under each operation's documented invalidation rules.

Detailed Description

App-wide owner and public access point for Flow element runtime data.

Obtain the initialized manager through App::elements(). State belongs to an element instance in a particular window; resource payloads are shared by all instances of one definition within the app. Use prepare() to create resources ahead of the first invocation. Definitions without state/resources remain valid. State pointers borrow manager storage and must obey each accessor's lifetime contract.

inlinenodiscard

Eagerly prepare the immutable app-wide resources of one definition or every definition in an ElementSet. Resource-free definitions are successful no-ops.

Hybrid contract: a resourceful definition without an initialized owner returns ObjectNotInitialized. Resource constructor and allocation exceptions propagate; already prepared definitions remain ready and preparation can be retried.

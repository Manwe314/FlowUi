Detailed Description

App-wide owner and public access point for Flow element runtime data.

ElementManager is owned by App. Its mutable controller and all future element state/resource payloads live in StorageSystem rather than on element definition statics. Applications obtain this manager through App::elements().

Definition metadata, window-owned state, app-wide resources, and state GC are all routed through its internal storage controller.
